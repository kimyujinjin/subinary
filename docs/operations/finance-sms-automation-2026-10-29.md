승인 정책은 모두 빈 목록이다. 테스트를 위해 운영 문자·거래·정책을 생성하거나 변경하지 않았다.
따라서 이번 배포로 실제 실패 문자가 자동 복구됐다고 보고하지 않는다.

## 사용하는 방법

가계부의 `할 일`(`/todo`)에서 같은 양식의 문자 묶음을 열고 대표 한 건을 확인한다.
기본 동작은 현재 한 건만 확정한다. 본인 또는 공용 카드를 지정하고
`같은 양식의 대기 문자와 앞으로 수신할 문자를 자동 정리`를 선택해야 개인 정책을 만든다.
단건 확인만 하면 기존 정책은 바뀌지 않는다.

worker가 부팅 시 및 5분마다 최대 100건을 순환 점검한다. 허용된 양식도 각 문자의 원문,
카드사·소유권, 단일 원화 승인 금액, 정확한 시각·할부, 중복, 계정·정책 유효성을 다시 검사한다.
링크·인증·명령 유도, 취소·외화·여러 금액, 모호한 카드와 시각은 자동 반영하지 않는다.
유료 모델 호출이나 Dot 예약 작업 없이 서버의 기존 계산과 승인된 추출 규칙으로 실행한다.

`문자 자동 정리 설정 → 자동 정리 중지`는 이후 적용을 막고 이미 생성된 거래를 유지한다.
처리 중인 작업과 중지는 DB 잠금 순서에 따라 먼저 완료된 작업을 기준으로 반영된다.

## Dot 연동 범위

금융 MCP 서버의 읽기 도구는 9개에서 10개로 늘었다. 새 도구는 본인 검토 묶음·자동 정리 설정과
`/todo?reviewSms=...` 경로를 반환한다. 원문과 쓰기 동의는 반환하거나 대행하지 않는다.
기존 무기한 읽기 연결의 권한·인증정보·만료 정책은 유지했다.

새 도구의 stdio 발견 및 실제 운영 API 조회, 원격 서버 동일 등록 함수의 HTTP 테스트는 통과했다.
기존 설치된 원격 플러그인의 `finance_quality`도 배포 후 성공했다.
**Dot 대화에서 새 도구 목록 갱신과 새 도구 직접 호출은 이번 실행에서 확인하지 않았다.**
Dot에 요청할 문구: “가족 가계부의 확인이 필요한 문자 묶음을 조회하고, 내가 확인할 항목의
가계부 화면 링크를 알려줘. 조회된 항목이 없으면 없다고 알려줘.”
