# 웹 UI 규칙

- 대화상자·확인창·선택 시트는 화면 폭과 상관없이 하단 시트로 띄운다(공용 `SHEET_POSITION`·`DIALOG_SHEET`, `components/ui/sheet-layout.ts`) — 사용자 결정, PC·태블릿에서 가운데 대화상자로 떠서 지적받음(2026-11-05). `sheet-layout.test.ts`가 고정한다.
- 시트 높이는 내용만큼, 최대 85%(`SHEET_MAX_HEIGHT`)로 두고 호출부에서 `max-h-*`로 늘리지 않는다. 위에 끌어내려 닫는 손잡이(`SheetHandle`)를 단다(확인창 제외) — 폰에서 상세가 화면을 거의 다 덮어 '바텀 시트가 아니다'라고 두 번 지적받음(2026-11-05).
- 상세 화면의 설정 값과 목록 필터는 라벨 붙은 드롭다운을 쌓지 않는다. 설정은 '이름 · 값 · ›' 한 줄, 필터는 칩 한 줄로 두고 둘 다 선택 시트(`transactions/picker-sheet.tsx`)로 고른다 — 사용자 지적, 입력 양식처럼 보여 디자인이 별로라고 함(2026-11-05).
