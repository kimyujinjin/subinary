# 웹 UI 규칙

- 창 모양은 용도마다 하나다: 상세 보기·선택지/안내만 바텀 시트, 확인(…할까요?)은 가운데 작은 창, 입력 폼은 폰에서 아래·넓은 화면에서 가운데, 값 고르기는 드롭다운(`components/ui/sheet-layout.ts` 표, `sheet-layout.test.ts`가 고정) — 사용자 지적, 전부 바텀 시트로 바꿨다가 '모든 걸 다 바텀 시트로 만들라고 한 건 아니었다'(2026-11-05).
- 바텀 시트(거래 상세·BottomSheet 위젯) 높이는 내용만큼 최대 85%(`SHEET_MAX_HEIGHT`)로 두고, 끌어내려 닫는 손잡이(`SheetHandle`)를 단다 — 폰에서 상세가 화면을 거의 다 덮어 '바텀 시트가 아니다'라고 지적받음(2026-11-05).
- 상세 화면의 설정 값과 목록 필터는 라벨 붙은 드롭다운을 쌓지 않는다. 설정은 '이름 · 값 · ›' 한 줄, 필터는 칩 한 줄로 두고 둘 다 누른 자리 아래 드롭다운(`transactions/picker-menu.tsx`)으로 고른다 — 사용자 지적, 입력 양식처럼 보여 디자인이 별로라고 함(2026-11-05).
